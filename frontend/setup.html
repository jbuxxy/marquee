Marquee setup

1. Log in

Use the admin password printed to the container logs on first boot (docker logs <container>).

2. Required connections

Seerr, and at least one of Plex or Jellyfin, are required before the dashboard unlocks. Everything else can be added later from admin settings.

Seerr required
Plex one of Plex/Jellyfin required
Jellyfin one of Plex/Jellyfin required
